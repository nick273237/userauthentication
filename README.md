this program is a simple python command-line application that allows user to register and log in with validation rules for usernames and passwords. 
User data is stored locally in a CSV file. There is user validation, password vaidation, attempts included in this program. IMPORTANT NOTES: passwords
are stored in plain text, which is not ideal for security. THIS PROJECT IS INTENDED WITH LEARNING PURPOSES ONLY. Possible improvements: Adding hashing,
adding GUI, replacing CSV with a database. Created as a Python practice project focused on: input validation, file handling, control flow, security basics.
